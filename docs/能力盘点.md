# 蓝色大肥鱼 · 能力盘点

> 盘点日期：2026-10-31　范围：`app/` 全部源码 + `app/assets/` 全部素材 + dsh 侧桥接
> 用途：确定「角色路线」下的补强顺序。本文只描述**现状**，不描述计划。

---

## 一、结论摘要

1. **对话侧已经比同类插件强一个量级**：人设分层、近期/长期记忆、流式语音、任务派发，这四件 dsh-pet 都没有对等实现。
2. **状态侧明显偏薄**：没有余额、待办、系统通知、多开。这些恰好是「挂件路线」的核心，与角色路线弱相关。
3. **Fish Audio 不是待补，是已上线**：`fish-tts.json` 显示 `enabled: true`、`voice_state: trained`、`model: s2.1-pro-free`、`preset: maid`。后续应理解为**补强**（音色/韵律/失效回退），不是从零接入。

---

## 二、定位

**角色路线**：她是一个住在电脑里的角色，dsh 是她「帮你干活」的一项能力，而不是她的宿主。

判断依据：

- 聊天与任务执行是两条独立通道（`dsh_companion.py` 里日常闲聊不走 dsh 会话，只有明确任务才提交）。
- 语音、记忆、性格是自建的，不依赖 dsh 的模型连接也能保留人格。
- 断网 / dsh 未启动时，动画与本地互动仍完整可用。

## 四、dsh 侧还能借什么

桥接目前只用了「会话 + 任务视图」这一小块，dsh 本体还有这些没用上：

| dsh 能力 | 能拿来做什么 | 对应缺口 |
|---|---|---|
| `dsh-schedule`（at / after / fixed-rate 提醒） | 待办与定时提醒挂到她头顶 | 待办、通知 |
| `dsh-jobs`（后台任务注册表） | 长任务进度条、完成回调 | 任务可视化 |
| usage / cost 记录（session 里的 `usage` 字段） | 余额/花费分档播动画 | 余额 |
| `dsh-attachment` | 她「递给你一个文件」 | 互动 |
| `dsh-skill` / `dsh-persona` | 人格与技能包热切换 | 人设分层已自建，可选合并 |
