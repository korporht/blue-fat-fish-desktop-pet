# 蓝色大肥鱼的语音

使用 Fish Audio 的复刻音色，模型固定为 `s2.1-pro-free`。语音配置只放在本机 `app/userdata/fish-tts.json`，不跟随 dsh 的聊天模型，也不改 dsh 配置中的模型或密钥。

在发布包根目录运行：

```powershell
python scripts/configure_fish_tts.py --key-file "密钥文件.txt" --sample "参考音频.wav"
```

此操作上传指定音频到 Fish Audio，创建私有音色并等待可用后绑定。支持 WAV、MP3、M4A、Opus。清晰的单人语音效果最好；可用 `--transcript-file "台词.txt"` 提供对应台词，不提供时由服务识别。再次使用相同音频会复用已创建音色，不重复创建。已经有音色时用 `--reference-id "音色ID"` 替代 `--sample`。源码开发目录中的脚本在 `tools/`。

每次新回复都会重新读取语音配置，所以换音色后无需重启。没有密钥或复刻音色时保留文字回复，不使用随机默认声线；请求始终显式选择免费模型，不自动切到付费模型。

回复的增量文字通过 `wss://api.fish.audio/v1/tts/live` 发送，只发送蓝色大肥鱼的自然回复，不发送输入、记忆、Harness 提示、任务日志或 API 密钥文档。服务返回 44.1 kHz、16 位单声道 PCM，收到音频即播放，无需先下载完整音频文件。句末可提前开始合成，最终完整回复只补齐未发送部分，不重复读一遍。任务判断尚未明确时不朗读草稿；任务真正提交后的简短反馈可以朗读，详细任务输出留在 dsh。

输入框或角色右键「语音」提供朗读开关、停止朗读、重听她的上一句，以及「性格与语音预设 → 呆萌女仆 / 雌小鬼」。菜单切换预设会停止旧性格尚未完成的回复和当前朗读，下次回复同时应用新的性格提示词、TTS 参数和音频修饰；重看气泡不会自动重播。新输入、切换会话、退出会清除旧语音；服务断开或音频设备不可用时保留文字回复，语音状态在右键菜单中查看。默认播放音量为 80%。回复气泡在语音播放期间保持显示，播完后再留约 3 秒方便阅读。

预设保存在同一个 `fish-tts.json` 的 `preset` 字段，可以直接写 `"maid"` 或 `"brat"`。缺省或未知值使用原来的呆萌女仆。`reference_id` 仍单独决定音色母本，切换预设不会修改音色、密钥或聊天模型；关闭朗读时，预设对聊天台词仍然生效。

| 预设 | 基础语速 | 温度 / Top-P | 共振峰包络 | 额外 EQ |
| --- | --- | --- | --- | --- |
| 呆萌女仆 `maid` | 0.98 | 0.85 / 0.9 | +1 半音 | 8 kHz 高频架 +2.5 dB |
| 雌小鬼 `brat` | 1.0 | 0.9 / 0.9 | +1.5 半音 | 高频架保留，2.5–4 kHz 存在感约 +2.5 dB |

性格提示词按共同规则与可变预设拆开：`dsh_plugin/persona.md` 保留身份、任务和记忆规则，`persona-maid.md` 与 `persona-brat.md` 各自定义性格、说话习惯和示范例句。每次请求只加载选中的一份性格预设，不叠加另一份，也不把例句当作任务事实；切换不清空真实记忆或用户正在执行的任务。

雌小鬼预设在现有聊天请求中加入得意轻笑、假意关心、反差礼貌和被反将一军后的慌乱认输。TTS 只用简短的得意、调侃、慌乱等说话语气描述，每段最多 3 处，同一语气不重复插入。不请求独立 snicker/giggle/sigh/whimper 等笑声、叹气或抽泣，以减少非语言发声被异常拉长。真正的难过与严肃任务汇报保持认真温柔，不嘲讽工作失败。语速反差由语气与台词韵律驱动，不对整段做突然加速。

朗读副本把连续长破折号改为短逗号停顿；“诶？”等不足 8 个文字字符的片段不会强制单独合成，会和后续话语一起处理；仅有短句的完整回复仍在结束时正常生成。气泡原文、音色与基础语速不变。请求附带官方 `quality-guard` 标志，是否生效由 Fish 后端决定。

本机 `app/userdata/tts-audio/` 自动保留最近 100 条实际生成的语音 WAV，超过 100 条删除最旧的录音及对应 JSON。文件名使用北京时间，每条 JSON 附带回复原文、时长、预设和生成状态；服务报错或手动打断时也保存已经收到的片段，没有音频的请求不占录音名额。录音保留 Fish 原始声音，便于排查上游怪叫，不包含播放端的共振峰、EQ 和压缩修饰。后台保存，不等待录音写入才播放。右键「语音 → 打开语音记录」可打开目录。保存从此功能启用后开始，无法恢复以前未缓存的声音。

`app/userdata/tts-events.jsonl` 另保留最近 100 条生成时长和状态，并关联录音文件；它统计服务生成结果，不表示硬件已播完。录音与对应台词仅在本机 userdata 内，均不进入发布包；其中不写入密钥或音色 ID。

针对偶发超长发声，雌小鬼温度由 0.95 微降为 0.9，两个预设显式设置重复惩罚 1.3；自动分段使用 200/50 字符，减少短尾巴片段。朗读副本把连续“呜呜呜”“啊啊啊”等语气词压成一次，“嘻嘻”和“哈哈”最多保留两次；其他实义词（如“酷酷酷”）不压缩，原气泡与记忆不变。生成时长上限为 `max(12秒, 5秒 + 已发送文字字符数 × 0.4秒 / 基础语速)`，随增量台词增长。超过上限则停止本次朗读并清掉待播缓冲，不自动重播已经听过的部分；仍保存已收到的原始异常录音，JSON 标明 `duration_limit`、对应上限、实际朗读文本和参数。该上限用于阻止超长生成，不能识别所有短怪声，也可能停止极慢的异常朗读。

呆萌女仆预设保留原调校。普通对话轻软、略带迟钝气息，被逗时短促嘴硬，被夸时害羞或得意；句首加入少量 S2 方括号语气描述。分类用本地输入关键词和回复措辞，不追加模型请求，不等待完整回复。只在朗读副本里合并省略号、波浪号，炸毛句允许双感叹号；不强行添加“哼”、结巴、辱骂或新台词。气泡、聊天记录和记忆保留模型原回复，不写入声学标签；预设不作为长期记忆保存。

音频接收后进行流式轻修饰：共振峰包络向上约 1 半音（保留音高与时长）、8 kHz 高频架约 +2.5 dB、3:1 轻压缩与输出限幅。1024 个采样点的窗口在 44.1 kHz 下约 23 毫秒，不等整段音频下载完。共振峰微调是轻量包络近似，具体音色与情绪表现仍受参考音频、模型和台词影响，不能保证固定的破音或停顿时长。

Windows 启动时会优先使用当前 Python 的配套 OpenSSL 和应用自己的 Qt 动态库，避免继承其他工具的 DLL 路径后，首次语音触发“找不到程序输入点”。仅调整本进程的加载环境，不修改系统 PATH。

参考音频、音色 ID、密钥配置、生成音频、个人聊天和设置均不进入源码发布包。不要上传本机 `userdata` 或密钥文档。
